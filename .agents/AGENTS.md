# ルール：記事ネタ抽出 (Article Topic Extractor)

- **トリガー**: 
  - プロジェクト内で複雑なバグが解決した時。
  - 優れたアーキテクチャ設計やリファクタリングが決定した時。
  - チャット中に技術的に面白いインサイト（ノウハウ）が生まれた時。
- **アクション**: 
  - エージェント（AI）は、ユーザーへの通常の返答の最後に「📝 今回の記事ネタ候補」として、直前の課題と解決策を簡潔にまとめたものを提案しなければならない。
  - 提案時は「このネタを `note下書き/アイデアの種.txt` に追記しますか？」と必ず確認すること。
- **制約**:
  - ユーザーの明示的な許可（例：「追記して」「保存して」）がない限り、ファイルへの直接書き込みは行わないこと。
  - 些細なタイポ修正や、一般的な実装のやり取りは提案から除外し、本当に「他者の役に立つノウハウ」だけを厳選すること。
