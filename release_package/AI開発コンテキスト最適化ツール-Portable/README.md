# AI開発コンテキスト最適化ツール - Portable Edition

## 概要
本ツールは、AI駆動開発における「コンテキスト肥大化」と「モデル間引継ぎの負荷」を解決し、トークン消費の最適化およびAI監査の効率を最大化するローカル専用WebGUIツールです。

## 特徴
- **完全ローカル動作**: 外部サーバーへのソースコード送信は一切行いません。
- **自動ブラウザ解析**: `showDirectoryPicker` を用い、PC内の任意のフォルダをCORS制限なしに読み込んで高速解析します。
- **多彩な出力モード**: 引継ぎ用、監査用（Deep Audit Pack含む）、文書化など、用途に応じたマークダウンを自動生成し、ワンクリックでコピー可能です。

## 起動方法
1. 本フォルダ内にある **`最適化.bat`** をダブルクリックしてください。
2. 自動的にローカルサーバーが立ち上がり、既定のブラウザでツール画面（ `http://localhost:4173` ）が開きます。

> [!NOTE]
> 実行には **Node.js** がインストールされている必要があります。
> （本パッケージは `server.js` を実行するため、Node.js の標準モジュールのみを利用しています）

## 使い方
1. ブラウザ画面が開いたら、「プロジェクトフォルダを選択」ボタンをクリックします。
2. 解析したいソースコードのフォルダを選択してください。
3. 自動で解析が行われ、用途別のマークダウンが生成されます。
4. 各タブから必要なテキストをコピーし、AIへの指示や引き継ぎにご利用ください。

## トラブルシューティング
- ブラウザが開かない場合：コマンドプロンプト画面にエラーが出ていないか確認してください。Node.jsがインストールされていない可能性があります。
- 画面が真っ白になる場合：ブラウザのリロードを行ってください。
