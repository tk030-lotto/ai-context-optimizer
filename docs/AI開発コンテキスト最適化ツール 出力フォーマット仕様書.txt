# AI開発コンテキスト最適化ツール

## 出力フォーマット仕様書

### 1. Chat Handover Format

```markdown
# Chat Continuation Summary

## Project

## Current Status

## Completed Tasks

## Current Task

## Next Task

## Constraints

## Known Issues
```

用途

同一AI内での新規チャット移行

## 出力共通ルール

### Markdown固定

全モード共通

### コピーペースト前提

外部連携なし

### AI依存なし

対象

* ChatGPT
* Gemini
* Sonnet
* Codex
* その他LLM

### 出力サイズ制御

原則

コード全文出力禁止

許可

* 要約
* 構造情報
* 依存関係
* 機能一覧

詳細コードは

Deep Audit Pack

利用時のみ出力する。

---

## 設計方針

本ツールは

「コードを出力するツール」

ではなく

「AIが理解できる知識へ変換するツール」

として設計する。
