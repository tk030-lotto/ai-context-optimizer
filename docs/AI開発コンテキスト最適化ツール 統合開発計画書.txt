# 1. プロジェクト概要

## プロジェクト名

AI Development Context Optimizer

## 開発目的

AI駆動開発において発生するコンテキスト肥大化問題を解決し、AIモデル間の引継ぎ、最終監査、文書作成を効率化する。

## 解決対象

* AIチャット移行時の情報喪失
* AIモデル間移行時の情報伝達負荷
* 最終監査時のトークン消費増大
* ドキュメント作成時の情報整理負荷

---

# 2. 開発方針

## 基本方針

* 完全ローカル動作
* 単体ツール構成
* API非依存
* MCP非依存
* Markdown出力
* AI非依存
* コピーペースト運用

## 対応言語

* TypeScript
* JavaScript
* Python
